
# Banco de Dados Loja

Programação e Desenvolvimento de Banco de Dados.

## Tecnologias utilizadas
- MySQL Community Server
- MySQL Workbench
- SQL

## Estrutura do projeto
- Loja.sql: script SQL de criação e manipulação do banco de dados.
- Loja.mwb: diagrama do banco de dados desenvolvido no MySQL Workbench.

## Funcionalidades
- Criação do banco de dados Loja.
- Criação das tabelas e relacionamentos.
- Inserção de registros.
- Criação da VIEW ContasNaoPagas.
- Consulta de contas não pagas.
